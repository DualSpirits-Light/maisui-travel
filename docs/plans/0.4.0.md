# 0.4.0 implementation plan

Goal: extend 0.3.1 without losing local travel/media or changing license/share compatibility.
Architecture: native Java UI and existing SQLite JSON snapshot store. Add optional portable tags; separate repositories for preferences and encrypted API configuration. Provider adapters centralize map and AI requests. Existing sharing, license heartbeat, daily update cadence remain.

- [x] About and support: original posters, user-facing release history, per-version first-launch notice, cached donations feed, email/browser actions.
- [x] Advanced settings: independent themed page, encrypted configuration snapshots; validate requests before replacing saved values; reset settings only after exact phrase.
- [x] Maps: provider registry for Amap/Tencent/Baidu REST search/routes/navigation; blank production keys, official validation; preserve old source links and offline map geometry.
- [x] Tags/search/memories: optional fields migrate old JSON, portable labels, editable grouped search with combined ranges, previous-year exact-day or ±3 memories.
- [x] Explore/AI: extensible reveal page, encrypted editable providers (compatible and Gemini adapters), Baidu search, structured plan preview/repair/import conversion; optional map context with no-tool fallback.
- [x] Verify: pure model/security/migration tests, Android build and integration/UI screenshots, provider response fixtures (live credentials unavailable), APK credential scan, regression of sharing/license/update.
- [ ] Release 0.4.0 versionCode10: original signer; GitHub user-facing release notes; Cloudflare metadata only after assets publish.

Compatibility decisions: keep SQLite snapshot schema rather than introducing Room; auto-check once per day when enabled; use real existing GitHub repository. Never copy the private source requirements file or credentials into public repository. Test secrets are outside repository and never compiled. Documentation references only public provider docs.
