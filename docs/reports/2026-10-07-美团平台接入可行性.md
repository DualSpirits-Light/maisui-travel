# 美团平台接入可行性

核查日期：2026-10-07。依据官网首页、AI Hub、Skill列表及旅行技能详情、MCP列表及天气Tool列表的公开页面。本轮只读调研，没有注册、实名认证、创建Token、安装CLI、调用鉴权接口或修改App。浏览器后续读取视觉服务详情时超时，因此视觉能力仅按列表简介判断。

## 结论

适合优先评估旅行查询、酒店/景点推荐和天气；不适合作为现有地图、热力、即时地点搜索的整体替代。商家经营接口不能当作任意消费者数据查询接口。

## 官方页面与已确认能力

- [首页](https://developer.meituan.com/)区分三方服务商、连锁品牌、个人开发者，个人入口宣传实名认证后免费接入MCP/Skills。这不是每个服务永久无限免费或没有并发限制的承诺。
- [旅行Skill详情](https://developer.meituan.com/ai-hub/skill-list/detail/12)：meituan-travel覆盖目的地/攻略、酒店、机票/火车票、门票、交通咨询，使用个人开发者Token及官方旅行CLI。文档预计耗时1～2分钟，价格可能含脱敏占位符，不应猜测还原；页面要求保留来源与返回价格。未验证可直接用于Android或Cloudflare Worker的稳定REST接口、结构化导入格式、商用分发及长期缓存许可。
- [天气MCP详情](https://developer.meituan.com/ai-hub/mcp-list/detail/11)：工具包含经纬度短时预报、未来十五天预报和实时天气。简介还提及预警，但本次Tool列表未见独立预警工具，不能将其列为已验证接口。没有实际调用验证返回字段、准确率、坐标系和延迟。
- [MCP列表](https://developer.meituan.com/ai-hub/mcp-list)：视觉AI简介提及OCR、图像理解、AIGC，可作为票据识别备选；具体票据种类、工具、费用、准确率未验证。订单、预约、券信息等条目描述均围绕商家业务，不证明可读游客个人订单。
- [Skill列表](https://developer.meituan.com/ai-hub/skill-list)：本次生活服务分类有旅行、跑腿、专属优惠助手。未找到可据此确认的个人开发者“全国餐厅评分/评论/人均消费自由查询”能力。

## 与麦穗旅序的映射（设计建议，不是已实现）

| 能力 | 建议入口 | 价值与限制 |
| --- | --- | --- |
| 旅行查询 | 探索中的美团旅行助手 | 输入城市、日期、人数、预算，查询酒店/景点/出行方案；异步显示、可取消，不能阻塞首页或地图 |
| 酒店/门票推荐 | 住宿、地点详情的查询入口 | 展示官方返回信息和链接；交易先交给官方页面，不开发本地支付、抢票或自动下单 |
| 天气 | 每日行程、出行速览 | 规划日期在支持范围内才展示预报；注明来源和更新时间；远期不生成假天气 |
| OCR | 预算照片、资料导入 | 先识别后人工确认日期、金额与商户；不自动记账，待具体工具与成本验证 |
| 优惠助手 | 可选福利入口 | 与行程核心关联较弱，暂不优先；不能为了优惠引入强制登录或自动领券流程 |
| 跑腿/商家管理 | 暂不接入 | 与旅行规划核心关联弱，订单/核销/广告经营接口不适合当前产品 |

## 关键边界

1. 没有核实的餐厅评分/评论、实时排队人数、人流/拥挤值、景区精确人数，不得因为平台有“餐饮排队”“评价查询”字样就宣称可获取。需另行确认消费者授权、商家授权及应用资格。
2. 保留已确定的高德地图、路线与地点搜索默认；美团仅补充内容/交易查询。不同来源的评分分开展示，匹配地点须核对城市、地址和坐标，不能只靠重名。
3. 旅行Skill当前是Agent+CLI形态，不能把CLI文件直接塞进Android，也不能假定Cloudflare Worker可运行Node CLI。先确认官方HTTP/MCP接口或适合的后端运行方案、费用，再确定架构。
4. 原始推荐结果与用户本地可编辑行程分开。转成草稿需确认返回结构和平台展示/使用约定；不存在已验证“一键结构化导入”契约。用户确认后才落入行程。
5. 对外查询只发送必要需求；设备精确坐标不默认上传。Token不内置APK、不写普通日志或分享包。使用用户自配凭据还是运营方凭据，应先确认平台是否允许面向多用户分发以及凭据归属。

## 接入前需要核实

- 个人开发者实际可开通哪些服务，是否允许集成独立Android App；实名资格及正式上线要求。
- 各服务免费额度、QPS/并发、超限行为、收费规则、是否能硬性阻止付费。
- 旅行能力是否有官方HTTP/MCP访问契约、响应字段、超时/取消、价格及链接有效期。
- 数据展示、缓存期限、来源标识、图片使用、转成可编辑草稿及再分享的允许范围。
- 门票/酒店链接和订单能力的授权范围；不能把商家订单API用作消费者订单同步。

公开页面没有足够材料确认以上数字和许可。建议先完成个人开发者开通，由控制台权限与正式协议核实，再用一两个不含个人隐私的城市查询做验证。当前推荐顺序：旅行查询/住宿门票 → 天气 → 票据OCR；全国餐厅数据和实时排队暂列待确认。
