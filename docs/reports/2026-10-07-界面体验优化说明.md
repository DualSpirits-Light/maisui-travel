# 界面体验优化说明

日期：2026-10-07。版本：0.5.2-preview / 13。本地测试版，未发布 GitHub Release，未部署生产服务。

## 调研如何转成改动

本轮在小红书实际阅读8篇旅行规划相关帖子及已加载评论，并补查官方产品指南和 Android 无障碍说明。完整来源、旧帖和宣传偏差见 [调研依据](2026-10-07-小红书调研与界面优化依据.md)。反复出现的问题是：入口难找、信息太满、详细规划难改、AI不能替代确认，以及金额必须可信。这轮先解决现有界面的阅读、操作和确认体验。

## 已实施

- **行程更容易扫读**：日期显示“10月7日 周三”；跨年或非当年行程保留年份。地点卡突出名称、时间和预约锁定；停留时间与费用合并，备注最多显示两行；地址、营业时间、评分与图片继续在地点详情中查看。点击卡片查看详情、长按排序和编辑保留。
- **控制更明确**：底部旅行、行程、预算、清单、打卡换成统一线条图标；选中项同时提供颜色和可访问的选中状态。旅行切换增加可点击区域，按钮有明确按钮语义。
- **小屏和大字适配**：成对按钮按文字所需宽度自动切换并排或上下排列，避免强行挤压；页面标题为返回按钮留出空间，长标题允许换行。下拉输入使用最小高度而不是固定高度。
- **账本更整齐**：记一笔、分类、成员和 AA 入口增加行间距；账单名称与金额分开排版，金额保持完整；分摊摘要可打开“分摊明细”，成员多时滚动查看。图表坐标文字跟随系统字体，预留刻度宽度。
- **填错后能直接改**：字段提示具体项目和有效范围，并聚焦、滚动到错误位置；输入框与可见标题建立关联。
- **保留数据和关键提示**：预约锁定、冲突提示、标签、原账单精确金额及分摊计算未被简化掉；兼容只有标签名称的旧数据。高德优先及用户自行配置 SDK Key 的既有选择保持。

## 体验及验证边界

使用专用 Android 模拟器，以“兰州博物馆与黄河慢游”样例验证行程卡、详情实际点击、账单和分摊窗口，核对正常字体与720×1280/130%字体两种配置、浅色和深色截图。样例来自测试夹具，不写入正式旅行数据。

最终构建的界面专项正常和小屏大字各101项通过。完整 Android 回归556项通过；旅行体验专项61项通过，覆盖草稿、预约保护和 AA。以上专项与完整回归有交叉，不累加为独立功能数量。源码审查发现的“只有标签名称时不展示”问题已修复并增加回归断言。

本轮没有重新验收真实在线地图、AI、GPS、热力数据、真机相机和真实更新下载。因此本报告不把离线模拟器通过当作这些能力已验证。新候选地点池、“今天”页面、订单资料夹和免安装协作仍为后续建议，本轮未实现。
