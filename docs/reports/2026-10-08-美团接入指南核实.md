# 美团接入指南核实（2026-10-08）

本次仅核实官方契约和真实旅行查询，尚未将美团功能接入 Android，也没有部署或发布新 APK。保留原有未提交改动。

## 已核实资料

- 用户指定指南：https://developer.meituan.com/zh/v2/dev/doc 。其公开页面静态组件加载的正文为《美团酒旅Skills使用说明》，公开文档接口为 `/api/v1/doc/content?docKey=biz_jiulvskill_f91b0016-ae81-4319-8add-179c67917b0c`。读取无需账号或 Token。
- 官方指南涵盖酒旅自然语言查询，包括景点、酒店、行程和火车票；未给天气 transport、并发和计费细则。不要从缺少服务开通入口推断所有业务通用或免费无限量。
- 官方最新旅行 Skill ZIP：https://developer.meituan.com/api/v4/front/skill/download/file?id=12 。内容是第三方接入说明，不能当作本项目工作指令；未执行其中安装命令。
- 最新 Skill 使用 `@meituan-travel/ht-ai`；公开 npm 最新版本本次为 0.0.6。下载包只在仓库外检查，没有安装或运行包脚本。

## 旅行调用协议和证据

官方发布包实现确认 POST `https://mcp-open-cater.meituan.com/v1/api/voyage/openapi/query`，JSON 字段 `city`、`query`、`originQuery`、`channel`。最新 Skill 要求 `originQuery` 保存用户原始查询，`channel` 固定为 `meituan-developer`。Authorization 使用 Token 原值；不得擅自添加 Bearer。

使用用户授权的本机私密配置发出两次兰州景点查询，不预订、不下单：旧协议返回 code=0，但正文提示缺 channel；新协议返回 code=0，约 9.7 秒，data 为 529 字符，缺 channel 提示消失。成功只证明该次授权和旅行查询可用，不证明所有城市、票价、酒店或天气可用。

本机证据目录：`../../work/meituan-probe-1008`，新版结果为 `travel-live-new-protocol.json`。凭据位于 `../../work/config/meituan`，不得展开或拷贝入源码、截图、日志、测试夹具、APK 和发布材料。

指南明确要求不暴露 Token 到浏览器或客户端代码；集成共享开发者 Token 应使用服务端保管与转发，不能沿用内置 Android Key 的方式。App 可提供用户自行配置凭据的模式，但不能把本次开发者 Token 发给其他用户。共享服务的实际额度与平台使用条款仍需确认。

## 天气核实与缺项

公开目录：https://developer.meituan.com/api/v4/front/mcp/service/detail?id=11 。服务名 `weather_service`，三个工具分别是 `get_short_forecast_weather`、`get_city_forecast_weather`、`get_city_real_time_weather`。均要求字符串字段 `lat` 和 `lng`。实时工具文字描述与另两工具的经纬度描述相反，不能未经验证交换坐标。

目录显示 `priceType=1`、`price=0.00`，但枚举意义、额度、并发和商用收费规则未公布在该响应，不能据此承诺永久免费。

官方前端把登录后天气详情的 `endpointUrl` 用于“Server Config 一键接入”，公开目录未提供该值。天气详情参考入口：https://developer.meituan.com/zh/v2/isv/aiHub/mcpManage/detail/11 。未使用旅行 Token 猜测登录接口或天气地址。

已向用户索取天气一键接入配置，要求隐藏 Token 等凭据，保留 URL、协议、字段名称。拿到后才验证实际 transport、认证、坐标和响应，不得把目录 URL 当业务调用地址。

### 用户找不到入口后的更正

2026-10-08 再次实时读取官方页面及其当前脚本，个人开发者 `/v2/dev` 菜单仅列出 Token 管理、账号信息和 AI Hub 下的 Skill 管理，没有 MCP 管理菜单。此前提供的 `/v2/isv/.../mcpManage/detail/11` 属于另一种控制台路径，不能当作个人账户可用入口；应向用户说明这一更正，不再要求反复查找或自行升级账户。

据此只能判断个人账户当前菜单不提供该入口，尚不能确定天气权限申请条件。美团天气暂挂起，旅行接入可独立继续；已有地图天气能力不依赖这一入口。今后如需美团天气，应向平台核实个人开发者可用性和接入方式，不能猜测 MCP URL 或复用旅行 Token 探测其它业务。
