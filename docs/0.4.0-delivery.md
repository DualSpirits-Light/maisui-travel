# 0.4.0 交付说明

版本为 0.4.0 / versionCode 10，使用原安装签名，可覆盖升级。升级延续 0.3.1 分享、授权后台和每日更新机制。

## 功能与主要文件

| 范围 | 主要文件 |
| --- | --- |

## 数据与接口兼容

保留 SQLite JSON 快照表及 schema 2，没有破坏性建表升级。旅行与地点新增可选 tagIds/tagNames；旧数据没有字段时按空标签读取。标签和组保存于独立偏好注册表，完整备份携带注册表，恢复先验证并映射重名标签。TripStore 保存前回读验证格式，防止写入下次无法读取的数据。

API 配置使用 Android Keystore AES-GCM 加密；不写入备份、源码或安装包。地图和 AI 后台验证不直接保存，界面仍有效且配置版本未变时才原子写入。WebDAV 清除仅删除自己的凭据。恢复默认设置需要输入“我已知悉”，保留旅行、图片及授权。

无需新后端数据库迁移。本版沿用 Cloudflare 更新端点、三天分享和授权接口；发布 APK 后再更新服务端版本、地址及 SHA-256。

## 验证范围与已知边界

- 原签名构建通过；169 项 Android 集成断言、25 项后端测试通过；模型 35、地点导入 21、授权令牌 23、来源合并 14、AI 解析 9、捐赠解析 6 项断言通过，搜索和回忆模型测试通过。发行源码与 APK 私有凭据扫描通过。
- 地图三个适配器通过固定响应和 URL/坐标约定测试；此次未使用用户密钥完成真实服务商联网调用。服务商的地区限制、账户权限、配额和机型外部唤起仍需用户配置后验证。
- 内嵌地图为 OpenStreetMap；所选地图服务负责搜索、路线估算和外部查看。保留本地地点及直线动线，网络失败不删除数据。
- AI 支持兼容 Chat Completions 与原生 Gemini；地图参考为 REST 降级方案，未实现 MCP。模型输出仍需用户核实。
- 自动更新保留每天首次进入前台检查，关闭开关后可手动检查。赞赏图片保持原始字节；Android 8–9 的保存入口通过系统分享选择保存位置。
- 捐赠记录采用公开 JSON + 本地缓存，当前公开列表为空；后续可编辑 data/donations.json。不包含或推断私人捐赠信息。
