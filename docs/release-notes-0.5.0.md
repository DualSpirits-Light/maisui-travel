# 麦穗旅序 0.5.0

这一版围绕规划旅行、记录回忆和日常使用做了集中优化。

- 新增六套配色与自定义十六进制颜色，支持浅色、深色模式；旅行侧滑操作居中，选择窗口与提示框改为圆角设计，重新整理关于页。
- 地点详情集中展示时间、交通、地址、营业时间、评分和图文备注，可打开所选地图搜索，也可直接创建该地点的旅行打卡。
- 打卡按旅行整理，日期时间更易读；添加照片保留原图，可按需自由裁剪、旋转和绘画。改善定位权限、可用来源和超时处理。
- 旅行和地点显示已选标签，完善组合搜索与筛选；标签及标签组可自行添加、修改和删除。
- 改善 WebDAV 验证体验：失败保留配置窗口，错误原因使用中文展示；修正地图密钥平台类型与 AI 接入配置。
- 管理后台统一授权、捐赠和账户设置，支持管理员密码登录与改密；授权码支持恢复、续期、期限选择及安全查看，新旧记录明确区分。
- 更新窗口支持 GitHub 加速和 Cloudflare 两条线路、下载进度、后台通知、取消及重试。下载后校验完整性、包名、版本与签名，再由你确认安装。

保留原安装签名，可从 0.4.0 覆盖升级并保留本地数据。地图、AI 和 WebDAV 仍需有效的对应服务配置；后台下载完成后的安装需要系统确认。
