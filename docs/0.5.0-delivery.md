# 0.5.0 交付与发布准备

日期：2026-09-24。版本：0.5.0 / versionCode 11，包名 `cn.lvxu.travel`。正式发布与双线路验收已完成，详见[最终发布记录](superpowers/plans/2026-09-24-release-050-published.md)。以下清单保留发布准备时的边界；当前状态以最终记录为准。

## 本版范围

- 主题颜色、明暗模式、通用圆角弹窗、旅行选择窗口与关于页布局。
- 地图、搜索、AI 接口和 WebDAV 配置交互；地点详情、标签展示、搜索筛选、旅行打卡分组、照片编辑和定位回退。

- GitHub Release 与 Cloudflare R2 双线路更新：下载进度、通知、取消和重试；安装前校验 SHA-256、包名、版本号和当前安装签名。

实现与各阶段历史验证见 `superpowers/plans/` 中第 1–9 阶段检查点。第 10 阶段针对最终候选包的验证如下；真实公网双线路 APK 验收仍待执行。
