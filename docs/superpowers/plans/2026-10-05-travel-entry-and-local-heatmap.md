# 旅行录入与当地热力图 Implementation Plan

**Goal:** 完成用户 16 项优化，保留旧旅行数据、原图和高德默认服务。
**Architecture:** 表单原有模型兼容，新增纯逻辑 TravelFormRules；标签在独立窗口维护草稿；费用照片进入既有媒体归档链；百度城市热力图单独提供探索入口。
**Tech Stack:** 原生 Java / SQLite JSON / 高德 SDK / 百度地图 SDK。

用户授权自主决策和按需并行，不再按阶段询问。热力图来源为用户引用对话，仅采用经官方文档核实的城市热力图能力，不生成未经提供的实时人数、预测或拥挤分数。
