## 本阶段实现

- WebDAV 候选地址、用户名和密码会先连接验证，验证成功后才保存；失败或取消不会覆盖已有配置。
- 验证失败时编辑窗口保持打开，保留用户已填写的内容，并在窗口底部持续显示圆角错误提示。
- HTTP 401、403、404、405、429、5xx 及其他 100–599 状态码均显示实际状态码和中文原因；未知英文异常、服务器正文、私有地址不会直接展示。
- 超时、域名解析、连接失败、SSL 证书和用户取消均转换为中文提示。
- 验证成功后仅关闭 WebDAV 编辑窗口，设置抽屉保持打开，并局部刷新为已配置状态，避免关闭和重开页面造成闪烁。
- 验证期间锁定输入和保存按钮，取消按钮仍可用；取消正在进行的验证后，即使网络请求稍后返回成功，也不会保存配置。
