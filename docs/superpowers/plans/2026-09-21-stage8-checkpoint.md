## 实现

- 管理页按授权状态显示“吊销授权 / 恢复使用”，归档且已吊销的记录可分别“恢复显示”（保留吊销）或“恢复使用”（清除吊销和归档）。普通禁用按钮不显示等待光标，只有实际请求显示忙碌。
- 期限对话框提供 7、30、90、365 天、具体日期时间及永久选项；过期授权显示“续期”。恢复吊销不会自动续期或解冻，界面明确提示后续操作。
- 新签发码使用独立服务端 AES-256-GCM 密钥加密保存可查看副本；查看接口先写审计再返回。列表不含原码或密文。历史仅哈希码无法还原，后台解释原因并可补发独立新授权，原码、设备、状态均保留。
- 服务端增加 0006 增量迁移及授权码审计表，并修复期限、冻结、归档、删除的并发状态覆盖。迁移、密钥配置与回滚见 `server/license/LICENSE-CODES.md`。
- Android 移除 LVX1 旧码新激活入口、验签类及签发工具；历史已激活用户的本地权益按原有效期读取，未删除旅行数据。设置中的状态与在线授权区分显示。
- 管理页不再展示旧版离线策略，内部对旧客户端协议仍发送固定兼容值 7；服务端保留旧设备激活与刷新，防止现有用户因升级失效。
