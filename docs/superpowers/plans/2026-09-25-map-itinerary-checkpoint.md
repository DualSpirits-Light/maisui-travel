## 阶段一结果（2026-09-26）

代码实现和离线配置/入口验证完成，等待用户确认进入第二阶段。

- 移除清单 Key 元数据、Gradle 环境/local.properties 注入、PowerShell 的 AmapKeyFile/环境变量注入；保留 SDK 依赖。
- `ApiConfig.amapAndroidKey` 通过现有 Android Keystore 加密存储，与 Web 服务 Key 分开。圆角配置窗口支持保存、取消、清除；显示当前安装包实际包名与签名 SHA-1。保存不代表在线鉴权成功。
- `AmapRuntime` 统一拦截未配置、未同意隐私、同进程更换 Key 的 SDK 使用。清除/更换/恢复默认设置销毁地图；更换已初始化 Key 提示重启；搜索回调拦截失效 Key。
- 默认高德入口接通 AmapUi，包含恢复/暂停/销毁和状态保存；拒绝隐私、设备不支持或初始化错误不自动回退 OpenStreetMap。用户主动选择其他提供商时保留原行为。
- 缺 Key 时从地图/地点搜索直接打开配置，首次保存后恢复刚才的入口；真实道路路线留到第二阶段，当前直线仍明确标注。
