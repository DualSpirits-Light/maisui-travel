## 实现

- `/console` 成为统一管理门户，包含授权管理、捐赠记录和账户设置。
- 管理员密码登录、修改密码、退出、八小时 HttpOnly/Secure/SameSite 会话、同源写请求校验与限流。密码以随机盐、服务端 pepper 和 PBKDF2 派生存储；数据库仅保存会话摘要。
- 独立 `ADMIN_RECOVERY_TOKEN` 可初始化或恢复密码，恢复/改密会原子撤销全部旧会话。初始化后旧 `ADMIN_TOKEN` 管理入口失效，既有授权和设备数据保留。
- 捐赠后台新增、编辑、删除记录，字段包括平台、捐赠人、金额、币种、日期、留言和公开开关；默认私有，金额以整数分保存。不同字段的并发 PATCH 不会把刚设为私有的记录重新公开。
- 公开 `GET /v1/donations` 只返回标记公开的展示字段；Android 读取该接口并保留原子离线缓存，在关于页显示公开捐赠记录。下载和缓存使用一致的 1 MiB 上限，超限不覆盖旧缓存。
- D1 增量迁移 `0004_admin_accounts.sql`、`0005_donations.sql`；管理员恢复、备份及回滚说明见 `server/license/ADMIN-ACCOUNTS.md`。
- 修复了退出后的迟到列表响应重新打开后台，以及过期会话下点击退出仍显示私人后台的问题。
